# Reading notes

> Working notes on the reference library. Each note records what a source proves, the exact regime it covers, and which research direction it feeds. These are notes, not summaries for their own sake.

## Index

- [`gross_zagier_kolyvagin.md`](gross_zagier_kolyvagin.md): the proven rank $\leq 1$ regime. Heegner points, the height formula, the Euler system, and the structural rank-1 ceiling.
- [`iwasawa_skinner_urban.md`](iwasawa_skinner_urban.md): the $p$-adic main conjecture, the $p$-part of BSD, and what stays open archimedean.
- [`statistics_function_field.md`](statistics_function_field.md): Bhargava-Shankar average rank, Bhargava-Skinner-Zhang positive proportion, and the Tate/Artin-Tate function-field template.

## Conventions

Each note states, up front: theorem or conjecture, the regime (rank 0, 1, or $\geq 2$; archimedean or $p$-adic), and the detector relevance. We never upgrade a conjecture to a theorem in the notes.
